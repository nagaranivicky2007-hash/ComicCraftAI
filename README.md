# ComicCraftAI 🎨🤖

AI Comic Generator using Gemini Flash - Create amazing comics from your stories!

## Features
- AI Story to Comic Panel Generation
- Export as PDF / Images
- Fast & Creative

## Tech Stack
- Python (Flask)
- Google Gemini API
- HTML / CSS

## How to Run
pip install -r requirements.txt
python -m app.main
